# The Core Lifecycle

The canonical coaching lifecycle is now understood as:

```txt
Training
→ Competition
→ Coach Interpretation
→ Weekly Direction
→ Parent Reinforcement
→ Longitudinal Athlete Development
→ Identity / Progression Synthesis
```

This is the governing product loop.

Everything else is infrastructure supporting this loop.

# Layer Definitions

## 1. Training = Proof Generation

Training produces:

* repetitions
* consistency
* system exposure
* skill focus
* attendance
* operational effort
* proof of work

Training is factual.

Training is NOT interpretation.

---

## 2. Competition = Pressure Validation

Competition produces:

* pressure-tested execution
* outcomes
* tactical validation
* composure exposure
* failure points
* strategic proof

Competition is factual.

Competition is NOT coaching meaning.

---

## 3. Match Breakdown = Coach Interpretation

This is the critical insight layer.

Coach match breakdowns are NOT:

* competition notes
* metadata
* commentary

They are:

# interpreted athletic truth.

Coach breakdowns capture:

* recurring technical patterns
* emotional tendencies
* hesitation
* urgency
* confidence
* pressure response
* tactical maturity
* strategic identity
* recurring gaps
* breakthrough moments

This is where meaning enters the system.

# Weekly vs Longitudinal

## Weekly Layer

Short-lived directional reinforcement.

Examples:

* mission of the week
* focus area
* study link
* parent reinforcement
* weekly drill emphasis
* temporary coaching emphasis

Purpose:
Immediate correction + reinforcement.

---

## Longitudinal Layer

Persistent athlete understanding over time.

Examples:

* recurring technical failures
* recurring emotional tendencies
* strategic identity development
* pressure adaptation
* coach interpretation history
* athlete evolution timeline

Purpose:
Developmental intelligence.
