# BJJ Tracker Dev Recap — 2026-04-23

## Summary
This session focused on fixing **parent confusion** in the This Week tab by enforcing a clear action flow and removing competing UI elements.

## What changed

### Action flow
- Established clear sequence:
  - **Watch → Training → Log**
- Removed duplicate training entry points
- Reduced competing CTAs

### Competition card
- Converted layout from row → column
- Tournament title now:
  - full width
  - 2-line limit
- Buttons:
  - stacked vertically
  - clearer primary vs secondary hierarchy

### UI simplification
- Removed redundant helper text
- Reduced instructional copy
- Repositioned Family Huddle as secondary support

## Product insight

The problem was not missing features.

The problem was:
- too many choices
- unclear priority

This pass removes that burden from the parent.

## Product direction

Move toward:
- guided experience
- not feature list

The UI should answer:
- what matters this week
- what to do next

## Next steps

1. Validate on device (real parent behavior)
2. Strengthen clarity of weekly focus
3. Ensure flow holds across states (linked, multi-kid)

## Risk

- Flow may still feel like separate tools instead of one journey
- Coaching signal may still be too implicit

## Open question

Can a parent:
- understand the goal
- take action

without explanation?

If not, flow is not solved.
